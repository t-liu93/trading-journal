- [数据模型](design/data-model.zh.md)：原始实体与设计理由。当前 ORM、迁移、API schema 和测试决定已实现行为，任务卡定义目标变化。

- [发布记录](release-notes/)：特定版本历史。当前安装看 README 和走查指南，不改写历史发布说明来充当新指南。
- 临时实现／评审／走查证据放在本地、被忽略的 `development-notes/<run-id>/`；已有 `review-notes/` 保留为本地历史，不将执行报告搬进受版本控制的文档。

## 维护

进度放在路线图／任务卡，稳定工作约定放开发指南，原始问题证据放 triage。未来每个里程碑用一个中英文文档对，同时包含共享决策、原子任务章节和简洁验收记录，不为同一契约拆出设计／实施／验收三份副本。中英文同次更新。
