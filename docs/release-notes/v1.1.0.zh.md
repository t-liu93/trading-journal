# v1.1.0 · 期权录入与交易日期一致性

> [English](v1.1.0.md) · **中文**

M-OPT-01 已完成，并通过五步用户走查验收。本版改进期权查找、带上下文的成交录入、日期和备注，不新增数据库迁移。

## 变更

- 品种列表和选择器默认隐藏过期期权，保留到期当天合约，提供历史开关与分页；已选历史品种继续按 ID 解析。
- Primary Instrument 解析到股票时，成交候选仅含该精确股票及其期权；切换主标的会清理旧搜索词及不兼容期权，保留其他已填字段。
- First Trade、后续成交录入和 PMCC Meta 的内嵌期权创建继承并锁定标的、币种和交易所；锁定品种显示名称，修复 UUID 标签缓存问题。
- 创建或归档成交后，开仓时间跟随最早有效成交；平仓默认采用最后一笔有效成交时间，倒置日期原子拒绝；冻结盈亏、归档及已平仓成交写锁继续生效。
- Position／Trade 返回的无偏移时间先按 UTC 解释，再显示为浏览器本地时间；本地选择 10:00，保存后仍显示 10:00，覆盖冬夏时差。
- 备注紧邻对应成交，保留换行、长文本换行并按字面显示类 HTML 文本；同行支持保存、清空、取消及 Ctrl/Command+Enter。
- 成交录入的标签、帮助和校验采用一致布局，保留多腿输入及 Position／首笔成交失败重试。
- CI 新增前端行为测试，与已有后端、类型生成和构建检查一起执行。

## API 兼容性

`GET /api/instruments` 新增 `offset`、`include_expired`、`option_underlying_id`、`related_underlying_id`，响应仍为数组。API 为兼容旧客户端默认 `include_expired=true`，产品界面显式请求 `false`。

`option_underlying_id` 仅限制期权行；`related_underlying_id` 将结果收窄为精确股票及其期权。全部筛选先于排序和分页。历史记录仍可按 ID 查找品种，并沿用 get-or-create 去重。

## 升级说明

本版无新增 Alembic migration 或历史数据回填。一致性备份后保留原数据库，使用现有先 migrate、后 app 的部署流程；不会自动重写已存时间或修复旧的已平仓记录。

版本镜像为 `ghcr.io/t-liu93/trading-journal:1.1.0`；现有发布流程构建 `linux/amd64` 和 `linux/arm64`，并更新 `1.1`、`1`、`latest` 别名。镜像发布不会替换正在运行的部署。参见[当前部署指南](../README_zh.md#部署)和[隔离走查](../walkthrough.zh.md)。

## 验证与验收

后端 Ruff、strict mypy 和 426 项测试通过；前端 57 项测试和生产构建通过，OpenAPI 生成类型已检查漂移。真实镜像和隔离全栈验证覆盖迁移、健康、登录、SPA 路由及代表性功能；真实 Chromium 核验两个内嵌创建入口与冬夏 Datepicker 往返。

用户完成五步走查，包含过期／历史／分页、主标的切换及创建、备注／布局，以及归档／重录／平仓后冻结盈亏 100 和成交写锁。

初始里程碑及 R1 搜索／筛选修复通过独立评审；后续 UUID 名称和时区回显修复通过自动／浏览器检查及用户验收，未另行独立评审。并非全部错误／API 分支均由用户逐项重做，详细边界见[里程碑验收记录](../plan/milestone-option-entry.zh.md#52-完成条件)。

## 保留范围

策略参数推导、多腿模板、已平仓记录审计纠错、Position／首笔成交服务端单事务及自动发布门禁继续延后。支持 SQLite，PostgreSQL 等价性未验证；行情、导入及货币换算不在本版范围。
